# Global memory index

Durable preferences and knowledge shared across connected projects. Read this file first and open only categories or records relevant to the current task.

Route project-specific decisions and domain facts to that project's local memory. Prefer a skill for repeatable agent behavior and `docs/` or a script for reproducible procedures.
